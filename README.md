# Klinika Pulsi

Klinika boshligʻi, vrach va menejer uchun ish jarayonini kuzatish paneli (prototip).

- **Boshliq:** bugungi koʻrsatkichlar, ogohlantirishlar, vrachlar yuklamasi, xodimlar
- **Vrach:** navbat, joriy qabul, tahlil kutayotganlar, topshiriqlar
- **Menejer:** bemorni roʻyxatga olish, bosqichlar boʻyicha kanban, topshiriq berish

Maʼlumotlar qoʻlda kiritiladi. Hozirgi versiya bitta `index.html` fayl; Claude Artifact ichida
`db` capability orqali maʼlumot saqlaydi, undan tashqarida ochilsa faqat brauzer xotirasida ishlaydi.

Bemor oqimi bosqichlari: Roʻyxatga olindi → Kutmoqda → Qabulda → Tahlil / UZI → Toʻlov → Yakunlandi
